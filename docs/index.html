HETEROGENEOUS COMPUTE

The Dual-Brain Heterogeneous Architecture

How Linux MPU throughput and Zephyr RTOS determinism communicate via MessagePack RPC.

LINUX APPLICATION DOMAIN (1.8V)

Qualcomm Dragonwing QRB2210

4x Arm Cortex-A53 @ 2.0 GHz | 4GB LPDDR4X | 32GB eMMC

  • 📸 60 FPS MIPI-CSI Vision: Sony IMX708 capture via dual Spectra 340L ISPs.
  • 🧠 MediaPipe 3D Landmark Extractor: 21 keypoints with wrist normalization.
  • ⚡ Qualcomm Adreno 702 GPU: INT8 1D-LSTM inference in 9.4 ms.
  • 🔊 Piper Offline TTS: Natural speech synthesis via I2S MAX98357A.
  • 🖥️ SmartElex 5" Touch UI: 800x480 real-time visual subtitles.
⇄ MessagePack RPC /var/run/arduino-router.sock < 1.8 ms Bi-directional Latency
REAL-TIME DETERMINISTIC DOMAIN (3.3V)

STMicroelectronics STM32U585

Arm Cortex-M33 @ 160 MHz | 786 KB SRAM | Zephyr RTOS

  • ⏱️ 1 kHz Deterministic Loop: Zero OS scheduler jitter.
  • 🎯 SG90 Pan/Tilt Tracking: 50 Hz closed-loop servo interpolation.
  • 📡 HLK-LD2410C Radar: 24 GHz presence auto-wake via UART.
  • 📶 SIM800C GSM Modem: Direct AT command offline SMS dispatch.
  • 💡 Safety Relays & Watchdog: 30-second auto-disarm hardware interlock.
  • 📊 Qwiic I2C Aggregator: SGP40, INA219, MPU-6050, DHT22.
